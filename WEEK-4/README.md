## Summary of Problems

| Problem | Description | Primary Concepts Covered | Time Complexity | Space Complexity |
| :--- | :--- | :--- | :--- | :--- |
| **[L1. Two Sum](./L1_TwoSum/README.md)** | Find two indices whose values sum to target | Nested loops, pairwise search | $\mathcal{O}(n^2)$ | $\mathcal{O}(1)$ |
| **[L2. Best Time to Buy and Sell Stock](./L2_BestTimeToBuyAndSellStock/README.md)** | Find maximum profit from single buy and sell | Single-pass traversal, running min/max | $\mathcal{O}(n)$ | $\mathcal{O}(1)$ |
| **[L3. Contains Duplicate](./L3_ContainsDuplicate/README.md)** | Check if any array value appears at least twice | Nested loops, early exit | $\mathcal{O}(n^2)$ | $\mathcal{O}(1)$ |
| **[L4. Merge Two Sorted Arrays](./L4_MergeTwoSortedArrays/README.md)** | Combine two sorted arrays into one sorted array | Two-pointer technique, while loop | $\mathcal{O}(n + m)$ | $\mathcal{O}(n + m)$ |
| **[L5. Rotate Array](./L5_RotateArray/README.md)** | Rotate array elements to the right by `k` steps | Modulo arithmetic, array copying | $\mathcal{O}(n)$ | $\mathcal{O}(n)$ |

## Compilation & Execution

You can compile and run any solution directly from the `WEEK-4` directory:

```bash
# Compile a problem
javac L1_TwoSum/Solution.java

# Run a problem
java L1_TwoSum.Solution
```
